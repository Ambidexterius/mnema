# Участие в разработке

Перед изменением прочитайте README и docs/ARCHITECTURE.md. Создайте ветку от main, объясните проблему и ожидаемый результат в pull request. Для заметного изменения добавьте запись в CHANGELOG.

Проверки:

```bash
npm ci --ignore-scripts
npm test
npm run build
```

Для интерфейса используйте Gravity UI, её типографику и модуль отступов 4 px. Иконки — Lucide. Новые действия должны работать с клавиатуры, иметь понятные состояния и сохранять доступность в обеих темах.

Права проверяются на сервере. Не добавляйте обход регистрации для production и не возвращайте демо-коды входа. Не отправляйте ключи, базы, записи интервью, персональные данные и реальные материалы в commits, Issues или скриншоты PR. Тесты должны работать на вымышленных данных.

CI проверяет код; автоматического доступа к Amvera или её секретам у GitHub Actions нет. Публикация выполняется отдельно владельцем проекта.
