# Мнемоника

Перед работой прочитать README.md, DESIGN.md, docs/ARCHITECTURE.md и docs/DEPLOYMENT.md. DESIGN.md обязателен при любых UI-изменениях и новых разделах: Gravity UI, существующие токены, Inter, сетка 4 px, исходные радиусы, максимум одна primary в активном контексте. Не вводить собственную систему кнопок, отступов или шрифтов.

Новый раздел добавить в scripts/ui-check.mjs. Проверять обе темы, 320/390/768/1024/1440 px, состояния, доступность и возврат навигации. Перед сдачей npm run check и npm run ui-check. Сохранить существующие роли и серверную видимость материалов; после асинхронного ввода повторно проверять доступ перед записью. Не подменять ответы реальной модели демонстрационными.

Использовать Ponytail Full, если установлен: минимальная полная правка, существующий код и зависимости. Если недоступен — сообщить, не выдавать за активный.

Исследования, БД, ключи, сессии и локальные стенды не публиковать. Деплой и публикация — по явной команде владельца, не автоматически после изменения кода. Выпуск 0.9.41 разрешён Глебом 16.11.2026; это не разрешение будущих выпусков.
