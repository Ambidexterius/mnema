# MnemoDuck

Источник: архив MnemoDuck_assets.zip, предоставленный владельцем проекта 17.11.2026 для замены логотипа и персонажа. В сопроводительном README графика описана как векторная адаптация пользовательского брендборда.

Использованы SVG static/logo-32.svg, static/favicon.svg, animations/{10,56}/*.svg и states_png/{10,56}/*.svg, а также static/favicon.ico. Геометрия и цвета не изменены; favicon завершения дополнен красной точкой. PNG/APNG, демонстрационные изображения и preview.html в поставку не включены.

Этот файл фиксирует источник материалов и не назначает им новую лицензию.
