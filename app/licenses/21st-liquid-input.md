# Liquid Multimodal Input

Border treatment adapted from Liquid Multimodal Input by Wensity Labs:
https://21st.dev/@wensity/components/liquid-multimodal-input

The component page identifies the source license as MIT. Original component
source was retrieved from the authenticated 21st interface on 2026-11-12 and is
retained in the private working reference, outside release output.

Mnemonika uses only the decorative conic-gradient border, adapted to the
existing Gravity composer, #EE204D brand color, 8 px corner radius, and reduced
motion. Attachment handling and the example model picker are not integrated.
