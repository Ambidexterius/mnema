# Подготовка 0.9.12

Статус: изолированная локальная ветка `codex/release-0.9.12-ready`, без публикации. До отдельной команды владельца не создавать релизные архивы и Docker-образ, не выполнять push в GitHub или Amvera и не сливать изменения в основную ветку. GitHub использует main, Amvera — master.

Включены компактные папки 232 × 186 px, их серверные действия и обновлённые находки. Только общий чат и папки на главной имеют радиус 12 px из --mn-home-radius; остальные элементы используют Gravity UI без глобальной замены её токенов. Между заголовком проектов и папками 32 px. Новый экран входа Matrix включён по отдельному подтверждению владельца. Экспериментальный обзор с закреплённым чатом не включён.

Данные пользователей, исследования, настройки доступа, секреты и __design не включены. Публичный адаптер импорта с MNEMA_IMPORT_SOURCE_ORIGIN сохранён; частный адрес исходной системы не переносится. Версия package.json/package-lock.json — 0.9.12. Production dependencies не менялись. Matrix поставляется с MIT-лицензией. Amvera checkout и настройки рабочих серверов на этапе подготовки не меняются.

До будущего выпуска:

1. Повторно сверить канонические исходники и состав ветки: параллельная локальная работа может продолжаться.
2. Запустить npm run check, runtime imports, реальные сценарии и обе темы в итоговой сборке.
3. По отдельной команде синхронизировать Amvera checkout, проверить runtime COPY и наличие актуального immutable образа. При смене production dependencies нужен полный runtime build.
4. Создать пакеты только с кодом и манифест с SHA-256; проверить отсутствие приватных данных.
5. По команде владельца отправить GitHub/Amvera, дождаться CI и запуска, сверить healthz и ресурсы. Только после этого отмечать версию опубликованной.
