# Подготовка 0.9.12

Статус: локальная ветка `codex/release-0.9.12`, без публикации. До отдельной команды владельца не собирать релизные архивы и Docker-образ, не выполнять push в GitHub или Amvera.

В ветке рабочие исходники интерфейса и серверных действий проектов. Экспериментальный обзор с закреплённым чатом не включён. Данные пользователей, исследования, настройки доступа, секреты и __design не включены. Публичный адаптер импорта с MNEMA_IMPORT_SOURCE_ORIGIN сохранён; частный адрес исходной системы не переносится.

Версия package.json/package-lock.json — 0.9.12. Production dependencies сохранены. Matrix поставляется исходником с MIT-лицензией. Amvera checkout и конфигурация рабочих серверов на этапе подготовки не меняются.

После команды на выпуск:

1. Повторно сверить канонические исходники и состав ветки: параллельная локальная работа может продолжаться.
2. Запустить npm run check, проверить реальные сценарии и обе темы в итоговой сборке. Текущие типы и тесты не заменяют проверку будущего артефакта.
3. Синхронизировать Amvera checkout, проверить все runtime COPY и существование актуального базового образа; при изменении production dependencies собрать полный runtime.
4. Создать пакеты только с кодом и манифест с SHA-256; отдельно проверить отсутствие приватных данных.
5. По команде владельца отправить GitHub/Amvera, дождаться CI и запуска, сверить healthz и ресурсы. Только после этого отмечать версию опубликованной.
