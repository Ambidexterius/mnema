# Мнемоника 0.9.30

Возвращена прежняя сетка страниц: контент шириной до 1104 px снова стоит по центру рабочей области. В 0.9.29 ограничение ширины и центрирование были убраны по ошибке — на широких экранах страницы растягивались, а чат на главной смещался влево. Одинаковые отступы от края до контента из 0.9.29 сохранены. Других изменений нет; данные, сервер и зависимости не менялись.

Проверки: типы, тесты и сборка; Chrome на 1920 px — главная и обзор проекта по центру, плавающее поле по центру.
