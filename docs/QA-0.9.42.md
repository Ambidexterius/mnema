# Проверка 0.9.42

Полный npm run check: типы, 156 тестов и сборка. Браузерный npm run ui-check использует реальную авторизацию и временную SQLite на вымышленных данных; настоящие LLM и SMTP заменены тестовыми обработчиками.

33 группы сценариев: обе темы, 320/390/768/1024/1440 px, существующие сценарии каталога/навигации/настроек/портала, отчёты первыми, одиночные C/T, русская раскладка, ввод и IME/автоповтор/модификаторы, сохранение выключателя, тултипы клавиш, центрированная загрузка 16 px, редактирование/отмена идеи, неактивный карандаш с пояснением, длинный заголовок, комментарий с аватаром и датой. Проверки узкого окна идеи включены.

Сервер отдельно проверяет автора идеи и границу срока: за 1 мс до 24 часов редактирование разрешено, ровно через 24 часа запрещено. Администратор не получает право редактировать чужой текст. Голоса, комментарии, статус, автор и время создания сохраняются; переданные клиентом значения этих полей игнорируются.

Safari, Firefox, VoiceOver, физические устройства и полный restore drill не проверены. Изменяющие сценарии портала выполняются на синтетических данных. Проверка токенов не заменяет полный аудит контраста.
