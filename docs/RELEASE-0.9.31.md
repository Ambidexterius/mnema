# Мнемоника 0.9.31

**Навигация.** Стрелка «Назад» на странице «Весь список» находок и на вкладке «Исследования» проекта теперь возвращает на предыдущий экран, как на карточке находки. Раньше она всегда вела к списку всех проектов. Если страницу открыли по прямой ссылке, стрелка ведёт на обзор проекта.

**Права доступа.**
- Скачивание исходного файла проверяет права так же, как предпросмотр. Читатель не скачает скрытый файл каталога, даже если знает ссылку.
- Если администратор понижает роль пользователя, роль меняется и в проектах, которые пользователь создал сам: без черновиков, редактирования и настроек проекта. Расширение доступа до всех проектов по-прежнему не понижает создателя в его проектах. Администратор может менять доступ создателя внутри отдельного проекта.

Проверки: типы, тесты (новые тесты падают на 0.9.30), сборка; путь «проект → Весь список → находка → Назад → Назад» и «проект → Исследования → Назад» в браузере. Данные и зависимости не менялись.
