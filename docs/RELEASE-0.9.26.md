# Мнемоника 0.9.26

Раздел «Пользователи» стал общим списком Мнемоники и открывается по `/users`. Его содержимое не зависит от последнего выбранного проекта.

По уточнению владельца существующие активные аккаунты и неиспользованные приглашения один раз получают доступ ко всем текущим и будущим проектам. Роли сохраняются, отозванные аккаунты не включаются заново. Новые приглашения по умолчанию общие; последующий явный выбор одного проекта сохраняется при перезапуске.

«Полный доступ» позволяет приглашать людей и работать с настройками. Назначать администраторов и отзывать доступ может только администратор. Управление собственным доступом заблокировано. В таблице участников добавлен флажок администратора; для приглашения роль администратора назначается после регистрации.

146 тестов, типы и сборка прошли. Проверены общая админка, миграция, ограничения ролей, приглашение обычным участником с полным доступом и назначение/снятие администратора. В production пользовательские данные и секреты не публикуются в Git. Незавершённая интеграция обратной связи не входит в выпуск.
