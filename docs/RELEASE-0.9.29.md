# Мнемоника 0.9.29

**Чат проекта стал настоящим чатом.** Первый вопрос в поле на обзоре проекта создаёт сохранённый чат, привязанный к проекту. Он появляется в «Последних чатах». Ответ открывается одной карточкой над полем; клик мимо или Esc сворачивают её, сноски открываются в боковой панели. «Открыть в чате» ведёт на полноэкранную страницу чата, где разговор продолжается; ссылка «Проект «…»» возвращает в проект. Привязанный чат ищет ответ сначала в своём проекте, а если там ничего нет — во всех доступных проектах.

**Сведения о проекте — как свойства в Obsidian.** Блок без заголовка, в порядке: автор, аудитория, метод, проведено, отчёт, контакт, добавлено, теги. Значение редактируется по клику, Enter сохраняет, Esc отменяет. «Проведено» выбирается в окне «месяц и год». Отчёт и теги — метки Gravity UI: «Есть» зелёная, «Нет» серая. На телефоне видны три главных свойства и кнопка «Все свойства», зоны касания 44 px, текст 16 px.

**Мелкие правки.** Статус «Черновик ИИ» переименован в «Предложено ИИ». В карточках находок на обзоре всегда видна повторяемость; ссылка «Все находки» стала «Весь список». Отступы страниц одинаковые со всех сторон. «Назад» на странице находки возвращает на предыдущий экран. Плавающее поле заметнее в тёмной теме и на телефоне.

**Сервер.** У сохранённых чатов появилось необязательное поле проекта: колонка `project_id` добавляется автоматически при запуске, прежние чаты остаются без проекта. Создать привязанный чат можно только с доступом к проекту; без доступа чат скрывается. В сведениях проекта появилось необязательное поле `tags` (до 20 тегов по 40 символов); клиенты без тегов сохранённые теги не стирают. Зависимости не менялись.

**Удалено.** Прежний чат проекта, который жил только в памяти вкладки, временная страница `/projects/…/chat`, выбор одного материала для вопроса и кнопка «Сохранить в PDF» под ответом проекта.

Проверки: типы, тесты и сборка; Chrome в светлой и тёмной теме, 375 и 1229 px. Реальные Safari/iOS/Android и экранные дикторы отдельно не проверялись.
