# Мнемоника 1.0.0 · 17 ноября 2026

Версия для мобильного веба. На экранах уже 960 CSS px находки и материалы проекта отображаются списком. Меню находится слева. В шапке раздела видно «Проекты», а у названия проекта есть один возврат. Зона нажатия стрелки 48 × 48 px, до названия 4 px. Серые блоки находок сохраняют внутренние поля 12 × 16 px. На компьютере сохранены таблицы и подписи «Исследования» и «Добавить материал».

В мобильном обзоре раздел называется «Материалы», кнопка «Добавить» открывает загрузку. Вкладка «Документы» показывает список файлов. Материал открывается первым. Сводка, хайлайты и находки доступны через подписанные вкладки. Можно открыть оригинал PDF, искать в извлечённом тексте и вернуться из цитаты к находке.

C и T доступны на компьютере. В компактном интерфейсе и при основном сенсорном вводе эти команды отключены, Enter в чате переносит строку. Кнопка отправки остаётся доступной.

Корпоративная регистрация требует подтверждения рабочей почты. Явное приглашение проверяется по своему токену, адресу и роли. Исправлены привязка подтверждённой почты к паролю для Safari и возврат к регистрации после выхода или истечения сессии.

Для проверки запустите npm run check и npm run ui-check с Node.js 24 и Chromium. Сценарий mobile project navigation and desktop table проверяет вид при 390, 1024 и 1440 px, размер кнопки назад и расстояние до заголовка. На релизном срезе также проверены чтение PDF и интервью, возврат к фильтру и обе ориентации Android 412. Мобильные проверки выполнялись в браузере. Проверка на физических устройствах остаётся открытой.
