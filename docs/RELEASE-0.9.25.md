# Мнемоника 0.9.25

Статусы пользователей: «Активен», «Ожидает регистрации», «Срок истёк», «Доступ отозван». Приглашение показывает срок и остаётся в списке после его истечения. Существующий аккаунт получает доступ сразу, новый — после регистрации.

Владелец сервиса может пригласить во все текущие и будущие проекты либо выбрать конкретный проект. Владельцы отдельных проектов приглашают только в свои проекты. Прежние права автоматически не расширяются. Сервер проверяет область доступа, роли и отзыв; общий доступ не даёт права управления проектом.

Обзор проекта открывается по `/projects/:id`, исследования — `/projects/:id/research`. Ссылки на материалы, находки и настройки содержат ID проекта. Старые hash-ссылки, приглашения и ссылки на фрагменты сохраняют работоспособность. Проверены обновление страницы, история браузера и запрет чужого проекта по прямому адресу.

Репозиторий также получает ранее подготовленные изменения 0.9.24: отбор источников, тематические разделы ответа и восстановленный звук завершения.

Проверки: 144 теста, типы и сборка; 108 браузерных проверок с синтетическими данными, обе темы, 320–1440 px. Реальная отправка новых приглашений, Safari и VoiceOver не проверялись. Открытый Select использует штатную реализацию Gravity UI 7.47.1; полный аудит скринридера не проводился.

Незавершённая интеграция обратной связи не входит в этот выпуск. Данные, БД и секреты в репозитории отсутствуют.
