# Проверка 0.9.41

Команды: npm run check; npm run ui-check. Последний запускает изолированный сервер, реальную авторизацию Better Auth и Chrome на синтетических данных. Внешняя LLM и SMTP заменены тестовыми обработчиками, приватные исследования не используются.

Покрытие: обе темы; 320/390/768/1024/1440 px; папки и кнопка создания; мобильная шторка, фокус и Escape; настройки, типографика и бледно-красный выбор; обратная связь и центрированный ghost; вторичные действия, поиск и ошибка новой идеи; находка → материал → находка → исходный список; мобильные настройки; прерываемое сворачивание меню и reduced motion.

Серверные регрессии: отсутствующий исходник → 404, обрезанный → 409, процесс продолжает отвечать; отзыв доступа во время медленного запроса → 401 без изменения данных. Метаданные размеров проходят существующую серверную видимость.

Ограничения: Chromium не заменяет физический телефон, Safari и VoiceOver. Проверка темы по токенам не является полным аудитом контраста. Восстановление всей системы из резервной копии и качество настоящей LLM/ASR в этот выпуск не входят.

Результат перед выкладкой: типы и build прошли; 155/155 серверных тестов на хосте; 25 браузерных групп сценариев без ошибок JavaScript. В изолированном runtime-образе — 153/153 теста (два SDK MCP-теста используют dev-only клиент и проверены полным host-набором). npm audit — 0 известных npm-уязвимостей на момент проверки; это не аудит Python/OS-пакетов.

Браузерная проверка дополнительно обнаружила и закрыла возврат фокуса шторки, выравнивание ghost-перехода, доступность ошибки новой идеи и единицы времени после CSS-минификации.
