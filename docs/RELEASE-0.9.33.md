# Мнемоника 0.9.33

**Токен для бота действует год.** Раньше токен MCP для бота действовал 30 дней. Срок уже выданных токенов не меняется: чтобы получить годовой токен, отзовите старый и выпустите новый. Подключения Claude и ChatGPT через OAuth не менялись.

**«Все проекты».** В окне «Токен для бота» и на странице, где ассистент просит доступ, над списком проектов появилась строка «Все проекты». Один клик отмечает все проекты, повторный снимает все. Если отмечена только часть, у строки стоит минус. Если у человека один проект, строка не показывается. В доступ попадают проекты, которые есть сейчас. Проекты, созданные позже, к уже выданному токену не добавляются.

## Что изменилось в коде

- `server/mcp.ts` — срок токена 365 дней вместо 30.
- `app/MCPSettings.tsx` — в компоненте `ProjectChoices` строка «Все проекты» на Gravity `Checkbox` с `indeterminate`. Компонент общий для окна токена и страницы согласия OAuth. Подписи о сроке токена исправлены.
- `server/mcp.test.ts` — проверка, что выданный токен действует год.
- `docs/ARCHITECTURE.md` — срок токена.

**Проверки:**
- типы, тесты и сборка;
- на локальном стенде с тремя проектами: выбор всех проектов, снятие выбора и частичный выбор; токен на все проекты выдан на 365 дней.

Данные и зависимости не менялись.
