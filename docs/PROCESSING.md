# Обработка и LLM

Видео: faster-whisper 1.2.1, CTranslate2 4.8.5, Whisper Small, CPU int8. Модель скачивается при сборке из официального Systran/faster-whisper-small, revision 536b0662742c02347bc0e980a01041f333bce120. Runtime использует локальные файлы. Один worker, части по 15 минут, максимум 4 часа/2 ГБ на запись. Спикеры определяются локально после распознавания: pyannote segmentation 3.0 (ONNX) и WeSpeaker ResNet34 через sherpa-onnx 2.0.1, части по 15 минут связываются по сходству голосов, голоса короче 10 с присоединяются к ближайшему. Для готовых записей есть отдельная задача без повторного распознавания. Короткие реплики («Хорошо») могут уйти соседу — их переносят вручную. Скорость зависит от CPU и записи.

PDF: Poppler сначала извлекает текст каждой страницы. Если его мало, Tesseract распознаёт растровую страницу с rus+eng. Лимит 100 страниц. Номера страниц сохраняются в сегментах. Структура сложных таблиц и рукописный текст не гарантируются. PDF с паролем требует предварительной разблокировки владельцем файла.

Исходники остаются в /data/uploads, временные изображения и аудио удаляются после обработки. Загрузка и чтение требуют активной серверной сессии. LLM получает только отобранные текстовые фрагменты при вопросе.

Amvera: https://inference.waw0.amvera.ru/v1, модель deepseek-V4, секрет LLM_KEY_DEEPSEEK. MNEMA_LLM_PRESET=amvera-deepseek-v4 добавляет подключение один раз и выбирает его по умолчанию. LLM_ALLOWED_HOSTS должен включать inference.waw0.amvera.ru. Другие OpenAI-совместимые API подключаются отдельно.

LLM_MONTHLY_TOKEN_LIMIT=2800000, LLM_MONTHLY_REQUEST_LIMIT=1200. Перед вызовом резервируется верхняя оценка токенов, после ответа учитывается usage.total_tokens. Ошибочный/неопределённый ответ сохраняет резерв. Лимит календарный UTC, период подписки поставщика может отличаться; он не заменяет контроль баланса Amvera. Автодокупки приложение не делает.

ASR_MODEL_DIR=/app/models/whisper-small, ASR_DIARIZATION_DIR=/app/models/diarization, ASR_DIARIZATION_THRESHOLD=0.7 (ASR_DIARIZATION=0 выключает), ASR_CPU_THREADS=1, OCR_LANGUAGES=rus+eng. Дополнительных ключей платного ASR не требуется.
