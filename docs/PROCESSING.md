# Обработка и LLM

## Локальные файлы

Видео: faster-whisper 1.2.1, CTranslate2 4.8.5, Whisper Small CPU int8. Модель берётся при полной сборке из Systran/faster-whisper-small, revision `536b0662742c02347bc0e980a01041f333bce120`; runtime использует локальные файлы. Предел записи — 4 часа/2 ГБ, аудио разбивается на 15-минутные части. Скорость зависит от CPU и записи; обработка дольше 30 минут сама по себе не доказывает зависание.

На CPU одновременно идёт одно задание ASR/OCR/спикеров. Ожидающие документы имеют приоритет перед следующей записью; текущую запись они не прерывают. Сводки и поиск находок используют независимую последовательную очередь внешней LLM и могут выполняться во время ASR.

Статусы различают ожидание и работу. ASR передаёт пройденный таймкод и часть, определение спикеров — отдельный этап. Это измеренный ход работы, без обещания времени завершения. Сервер пишет события старта, периодического состояния, завершения и ошибки; текст интервью в эти логи не включается.

Готовые части ASR атомарно сохраняются в приватном `/data/processing/<job.id>/asr.json`. После рестарта то же задание повторяет только незавершённые части; подготовка аудио и определение спикеров могут повториться. Новая явная попытка имеет новый job.id. Несовместимый или повреждённый checkpoint игнорируется. При обычном успехе/ошибке папка очищается, после гибели процесса остаётся для продолжения. Checkpoints содержат приватный исходный текст. Возобновление проверено локальными Python-процессами с подменёнными моделями; production-рестарт с реальной длинной записью ещё не проверен.

Whisper освобождается перед моделями спикеров. Спикеры определяются локально: pyannote segmentation 3.0 (ONNX) и WeSpeaker ResNet34 через sherpa-onnx 2.0.1. Части связываются по сходству голосов, голоса короче 10 с присоединяются к ближайшему. Имена не угадываются: подписи «Спикер 1…N» меняют вручную. Полная расшифровка сохраняется до этого необязательного этапа и остаётся доступной при его отдельном сбое. Незавершённая ASR не выдаётся за готовый текст. Для готовой записи есть отдельная задача определения спикеров.

PDF: Poppler извлекает текст каждой страницы. Если его мало, Tesseract распознаёт растровую страницу с rus+eng. Лимит 100 страниц, номер страницы сохраняется. Сложные таблицы, рукопись и точность OCR не гарантируются. PDF с паролем нужно предварительно разблокировать. DOC/DOCX извлекаются локально, картинки Word не проходят OCR. XLSX читается по сохранённым значениям с адресами ячеек, формулы не пересчитываются.

Исходники остаются в `/data/uploads`; временное аудио и изображения удаляются после обработки. Загрузка и чтение требуют серверной авторизации.

### Удаление материала во время обработки

`DELETE /api/studies/:id` доступен участнику с полным доступом в выбранном проекте. Для активной локальной задачи сервер посылает адресный сигнал отмены и дожидается фактического завершения дочернего процесса и очистки временных файлов. Перед удалением повторно проверяются сессия, проект и роль. Затем удаляются материал, его находки и хайлайты, задания, локальный исходник и checkpoints. Другие задания и проекты продолжают работать. Пока выполняется сводка или поиск находок, сервер возвращает 409; отмена локального файла не отменяет запрос к внешней LLM.

### Хранение без S3

При `MNEMA_S3_ENABLED=0` чтение, запись, зеркалирование исходников и резервное копирование SQLite в S3 выключены, даже если параметры подключения сохранены в серверных секретах. SQLite, исходники и checkpoints используют постоянный `/data` Amvera. Выключение не удаляет существующие объекты S3; такие копии перестают обновляться. Удаление локального материала при выключенном S3 не является удалением его старой удалённой копии.

## Модели и отбор доказательств

Поддерживаются совместимый Chat Completions API, OpenAI Responses и Anthropic Messages. Подключение выбирает владелец проекта; сохранённые через интерфейс ключи зашифрованы на сервере. Для Amvera preset используются URL `https://inference.waw0.amvera.ru/v1`, модель `deepseek-V4`, секрет окружения `LLM_KEY_DEEPSEEK` и `MNEMA_LLM_PRESET=amvera-deepseek-v4`; домен API должен быть разрешён в `LLM_ALLOWED_HOSTS`.

При вопросе LLM получает выбранные исходные фрагменты. Внутри каждого материала сначала выбираются все связанные цитаты наиболее релевантной видимой находки, затем цитаты следующих находок; между материалами сохраняется чередование. Основные ссылки множества находок не должны вытеснять позднее доказательство наиболее релевантной находки. Лексический поиск и бюджет источников ограничивают полноту; охват выборки передаётся с запросом. Исправление потери цитаты покрыто регрессией, но реальный повтор контрольного вопроса DeepSeek после правки ещё предстоит. Успешный HTTP-ответ поставщика не доказывает качество вывода.

Сводки и поиск находок читают весь допустимый текст частями и остаются черновиками ИИ. Перед каждым содержательным выводом исследователь проверяет цитаты. Реальные новые OpenAI/Claude API-ключи и внешние MCP-клиенты не проверены этой поставкой.

`LLM_MONTHLY_TOKEN_LIMIT=2800000`, `LLM_MONTHLY_REQUEST_LIMIT=1200`. Перед вызовом резервируется верхняя оценка токенов, после ответа учитывается `usage.total_tokens`. Ошибочный/неопределённый ответ сохраняет резерв. Период лимита — календарный UTC-месяц и может отличаться от периода подписки. Автодокупки нет; серверный лимит не заменяет контроль баланса поставщика.

`ASR_MODEL_DIR=/app/models/whisper-small`, `ASR_DIARIZATION_DIR=/app/models/diarization`, `ASR_DIARIZATION_THRESHOLD=0.7`, `ASR_CPU_THREADS=1`, `OCR_LANGUAGES=rus+eng`; `ASR_DIARIZATION=0` выключает спикеров. Дополнительных платных ключей ASR не требуется. Качество на корпусе, длинные интервью и полное восстановление сервиса требуют отдельных проверок.
